## 1. システム構成

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Hobo-JHS-Homepage |

## 3. ページ構成・コンポーネント設計

```
src/
├── app/
│   ├── layout.tsx            # ルートレイアウト（SEO・フォント・SVGフィルタ・OP用の先読みカバー）
│   ├── page.tsx              # メインページ（全セクションの組み合わせ）
│   ├── opengraph-image.tsx   # OGP画像の生成
│   └── globals.css           # デザイントークンと共通部品（テープ・カード・ボタン等）
├── lib/
│   └── event.ts              # 開催日時・残り日数・数字画像の位置計算
└── components/
    ├── OpSplash.tsx          # オープニング演出（あと◯日）
    ├── Header.tsx            # ヘッダー（ナビ・ハンバーガーメニュー）
    ├── Hero.tsx              # ヒーローセクション
    ├── CollageLogo.tsx       # 切り貼り風タイトルロゴ
    ├── Countdown.tsx         # カウントダウンタイマー＋祝・開催演出
    ├── EventOverview.tsx     # イベント概要（6枚カード）
    ├── TeachersMessage.tsx   # 恩師へのメッセージ
    ├── Schedule.tsx          # 当日スケジュール（Coming Soon）
    ├── Access.tsx            # アクセス・Google Maps
    ├── ContactForm.tsx       # お問い合わせフォーム（Formspree連携）
    ├── Footer.tsx            # フッター
    ├── Reveal.tsx            # スクロール登場演出
    ├── SvgDefs.tsx           # ちぎれ・破れのSVGフィルタと模様
    └── ui.tsx                # テープ・チップ・星・区切りテープ・セクション見出し
```

各コンポーネントのスタイルは同名の `*.module.css` に置く。

### 3.1 オープニング (OpSplash)
- 初回訪問時に、「開催まであと◯日」の数字を紙片で1枚ずつ貼る演出を約3秒流す
- 数字は1桁を4×6の紙片に分け、上の行から順に貼る。貼り終えたら黄色い紙のワイプでタイトルロゴへ切り替える
- 右下に「SKIP」ボタンを置く。Escキーでも閉じられる
- 一度見たらセッション中は流さない（`sessionStorage` の `op-seen`）。ヒーローのロゴを押すと再生し直せる
- 次の場合は流さない：開催日の0時以降、残りが1日を切ったとき、アニメーション低減設定、低速回線
- ハイドレーション前にヒーローが一瞬見えないよう、`<head>` のスクリプトが紙色のカバーを敷く（5秒で自動解除）

### 3.2 ヘッダー (Header)
- PC：左に3行組みのロゴ「HOBO JHS / REUNION / 2027」、右にナビ
- ナビゲーション：HOME / INFO / TEACHERS / SCHEDULE / ACCESS / CONTACT（ページ内リンク）
- 読んでいるセクションのナビ項目に赤テープの下線を付ける
- スクロールするとロゴが1行に畳まれ、ヘッダーが縮む
- モバイル：テープ3本のハンバーガー。開くと全画面メニューになり、ボタンが「✕」に変形する

### 3.3 ヒーローセクション (Hero)
- 黒テープの見出し「HOBO JUNIOR HIGH SCHOOL REUNION」
- 1文字ずつ色紙を切り貼りしたタイトルロゴ（保々中学校 / 新成人同窓会 / 2027）
- キャッチコピー：「あの頃の絆を、もう一度。」
- 日付「2027.01/10」（曜日 SUN は赤の縦書き）、18:00 開宴、会場名
- バッジ：「ビンゴ大会やります！」「豪華景品も用意！？」
- CTAボタン → お問い合わせセクションへスクロール
- カウントダウンを写真のように枠に入れ、テープで貼って見せる

### 3.4 カウントダウン (Countdown)
- 破れ紙の数字画像で DAYS / HRS / MIN / SEC を表示する
- 数字が変わると、その桁の紙だけが上から落ちてきて貼り直される
- 数字画像は `public/op/countdown-digits.webp`。`scripts/generate-countdown-digits.py` で生成する
- 開催時刻から12時間以内に開くと、紙吹雪と「祝・開催」のオーバーレイを表示する

### 3.5 イベント概要 (EventOverview)
- 6枚カード（日時 / 会場 / 会費 / 参加者 / 服装 / イベント内容）
- 先生注釈：「※恩師の先生方からは徴収いたしません」
- 会費のお支払いについて：振込締切・振込先の案内方法・期限超過時の扱い・キャンセルと返金・振込手数料
- 黄色い破れ紙に一言：「あの日の教室の続きを、ここで。」

### 3.6 恩師へのメッセージ (TeachersMessage)
- クラフト紙の便箋風カード（画鋲・テープ留め）
- 先生方を「特別招待」として迎え、会費はいただかない旨をマーカー風に強調する
- 署名「保々中学校 同窓会実行委員会」と朱色の落款風スタンプ

### 3.7 スケジュール (Schedule)
- 当日までの流れを日付ごとのカードで示す：11月中旬 振込先の案内（LINE）／12月6日 振込締切／1月8日正午 欠席連絡の期限／1月10日 当日
- 当日のタイムテーブルは Coming Soon（決まり次第掲載）

### 3.8 アクセス・地図 (Access)
- Google Maps 埋め込み（プラトンホテル四日市）
- 電車（近鉄四日市駅より徒歩約3分）・車でのアクセス案内
- 飲み放題プランのため、お酒を飲む人には公共交通機関での来場を呼びかける

### 3.9 お問い合わせフォーム (ContactForm)
- 入力項目：お名前（必須）/ 返信用メールアドレス（必須）/ お問い合わせ内容（必須）
- 送信先：Formspree 経由で `koshi1250@icloud.com` に自動転送
- 件名自動設定：「【保々中同窓会】{名前}さんからのお問い合わせ」
- 送信完了画面・エラーハンドリング実装済み
- 見出しの下で、欠席の連絡は1月8日（金）正午までに幹事へ伝えるよう案内する
- `NEXT_PUBLIC_FORMSPREE_ID` が未設定のときは送信せず、内容をコンソールに出す

### 3.10 フッター (Footer)
- イベント名
- コピーライト：© 2027 保々中学校 同窓会実行委員会
- 幹事個人の連絡先やSNSは載せない

## 4. デザイン要件

### 4.1 世界観
- 切り貼り（コラージュ）／ZINE風。紙の地に、ちぎれたテープと紙片を重ねる
- テープやカードは±1〜3°、散らした装飾は±15°程度まで傾ける。隣り合う要素は向きを変える
- ちぎれ・破れのSVGフィルタは文字には掛けず、`::before` の背景レイヤーにだけ掛ける

### 4.2 カラーパレット
- 赤：`#e31b23`
- 青：`#1a33d6`
- 黄：`#f4d21f`
- 墨（文字）：`#111111`
- 紙（地）：`#f8f8f8`、クラフト紙：`#f3ebd9`

### 4.3 タイポグラフィ
- 和文：Noto Sans JP（400 / 700 / 900）
- 数字・英字見出し：Bebas Neue
- ヘッダーロゴ：Murecho（700）
- 曜日・単位：Courier Prime（700）

### 4.4 アニメーション
- オープニング（3.1）
- スクロールで紙片が少し傾きながら貼られる登場演出（`Reveal`）
- タイトルロゴの1文字ずつの貼り付け、カウントダウンの貼り直し
- ボタンはホバーで逆回転しつつ少し拡大する
- アニメーション低減設定では動かさない。SSRで焼き込まれる初期状態は `globals.css` の `[data-reveal]` で打ち消す
